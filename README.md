# Myriad Knots（千千结）

`ST-MyriadKnots` 是 SillyTavern 的关系档案扩展，界面中文名为“千千结”。项目仓库：[github.com/atonal519/ST-MyriadKnots](https://github.com/atonal519/ST-MyriadKnots)。

## 当前 V2 范围

- 为当前单人聊天在 `qianqianjie` 聊天元数据中建立稳定 UUID；不会创建旧版 identity/meta 后端记录。
- 按用户点击时固定的截止楼层，分批扫描全部有效 AI 正文并保存 memory 记录。
- 扫描完成后由用户再次点击“整理人物”，跨批归并人物，并保留用户来源指针。
- 用户确认关注人物后，全部人物原子写入同一份 `archive-v2`；未关注人物作为同档案静默池保存。
- 只为关注人物生成基础人设草稿，用户确认后用 revision/CAS 写回正式档案。
- 千人档案支持查看、改名、编辑基础字段，以及关注／静默切换。
- 主 API 与副 API 可分别路由到共享主配置或共享预设；总开关关闭后不读取后端、不调用 AI。

历史初始化只由用户点击触发。关闭面板不会取消同聊天的后台扫描；切换聊天、切换 Persona 或禁用插件会使旧任务失效。新消息不会被追加入已经开始的初始化目标。

## 延期项

`千事` 时间轴审核、`双丝网` 关系旅程、`下一步` 建议、持续每 N 楼记忆、Persona 主动重绑、导入导出与关系图谱尚未实现。界面仅保留对应占位，不会暗中运行旧版业务。

## 安装

在 SillyTavern 的第三方扩展安装入口中粘贴仓库 URL。生产清单只加载 `dist/qqj-app.js`；设置与面板入口位于魔法棒菜单。
